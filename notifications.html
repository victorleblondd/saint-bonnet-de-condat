Sur cet appareil

Vérification…

Sur iPhone ou iPad

  1. Ouvrez saint-bonnet-de-condat.fr dans Safari.
  2. Touchez le bouton Partager (sur les versions récentes, il se trouve dans le menu « ⋯ »), puis « Sur l'écran d'accueil ». Si l'option « Ouvrir en tant qu'app web » apparaît, laissez-la activée. Touchez « Ajouter ».
  3. Ouvrez le site avec la nouvelle icône « Saint-Bonnet » de l'écran d'accueil.
  4. Touchez « Activer » dans le bandeau bleu en haut de l'accueil (ou revenez sur cette page), puis « Activer les notifications » et « Autoriser ».

Il faut iOS 16.4 ou une version plus récente. Sur iPhone et iPad, les notifications ne fonctionnent qu'à partir de l'icône de l'écran d'accueil.

Sur Android

  1. Ouvrez saint-bonnet-de-condat.fr dans Chrome, touchez « Activer les notifications » sur cette page, puis « Autoriser ».
  2. Pour avoir l'icône sur l'écran d'accueil : menu ⋮, puis « Ajouter à l'écran d'accueil » (ou « Installer l'application »).

Ce que vous recevrez

Une notification à chaque nouvel avis de la mairie publié dans Infos & Alertes : coupures d'eau, travaux, fermetures, événements. Elle s'affiche aussi sur l'écran verrouillé.

Vos données

Le site enregistre seulement l'adresse technique d'abonnement fournie par votre appareil : ni nom, ni numéro, ni adresse e-mail. Elle est hébergée dans l'Union européenne et supprimée dès que vous désactivez les notifications.
