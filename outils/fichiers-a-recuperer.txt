# (programme : outils/recuperer_fichiers.py, lancé par .github/workflows/recuperer-fichiers.yml).

# Une ligne par fichier :  adresse-source   chemin-dans-le-site   [option]
# - Si le chemin se termine par .pdf et que la source est une image (affiche), elle est convertie en PDF A4.
# - Option pour une photo : largeur maximale (par exemple 1400).
# - Option pour un PDF : pages=3-4 garde seulement ces pages (arrêté d'un recueil des actes administratifs).
# - Un fichier déjà présent dans le site n'est jamais téléchargé une deuxième fois.
